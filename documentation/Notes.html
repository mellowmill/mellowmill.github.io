Notes

Choose the folder that should hold your notes, then make the first boundary easy to understand.


What is a note

In MellowMill a note is the fundemental building block of the system, it is essentially a document where you can store text, tasks, images etc. Whatever you need to group together into a sensible slice of knowledge. 


On your disk it is stored as a file in a file format we have created specifically for helping you be productive. The files are stored as plain text and can be opened and read by most text editors in exactly the same way a Markdown file can be. This means that you can easily take your files do whatever you want with them. 


Createing a Note

Creating note is really easy, you simple need to click on the ’new note’ button in the menu header: 


When you click this button a new blank note will appear. You can simply type your note name in the first line and hit return to continue editing the note. 


The first line is always the name of the note that appears in the app and is the name of the file stored on disk. 


Every note must have a unique name. If you try and re-use an existing name MellowMill will display a warning asking you to pick a unique name.
