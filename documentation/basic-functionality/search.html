Basic functionality

Search your workspace

Search is the quickest way back to the thread you need when you remember the idea but not the note.

Search as you type

MellowMill searches across your notes, tags, and files. Start with the word you remember, then narrow the results as the list appears. You do not need to know which notebook contains the answer first.

Search works best with the language you actually used in the note. Try a client name, a decision phrase, a task verb, or a tag such as #launch.

Use filters to narrow the list

When a broad search returns more than one useful thread, use the notes filter palette to narrow the view. Combine a phrase with a tag or a focused term rather than inventing a new filing system for every topic.

You remember...Try searching for...
A project nameThe project name or its tag.
A decisionA distinctive phrase from the decision.
An open actionThe task verb or due-date language.
A related fileThe filename or a word from its note.

Build searchable notes

  • Give each note a clear, specific title.
  • Use consistent tags for recurring clients, projects, or themes.
  • Write decisions and actions in plain language.
  • Keep important reference files attached to the note they explain.

These habits make search a way to recover context, not just a way to locate a filename.

Search for meaning, not perfect filing. MellowMill is designed so the words in your notes do more of the organizing.
