Basic functionality

MellowMill keeps the everyday pieces of work close together: notes for context, tasks for action, tags for shape, and search for the way back in.

Keep context next to action

A task can live beside the reason it exists. A tag can connect related notes without forcing a second database. The result is a system that stays readable as it grows.

Free to use Notes, tasks, tags, local storage, search, and Markdown support are part of the everyday workflow.
