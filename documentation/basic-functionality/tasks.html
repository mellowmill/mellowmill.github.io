Basic functionality

Tasks

Keep the next action beside the context that explains it.

Turn sentences into tasks

Tasks are most useful when they keep their context. Write the action where the decision or conversation happened, instead of copying it into a separate list and losing the reason behind it.

Task syntax
- Confirm the brief, due 5th September
- Review the supplier options
- Share the recommendation with the team

Check tasks off as they are complete. MellowMill can also extract priority and due-date information from the text you write, so the task stays readable while remaining useful for tracking.

Keep the action connected

When a thought becomes work, add a task rather than moving the action into a separate list. The note keeps the decision, the source material, and the next step together.

  • Write the decision or context first.
  • Add the task directly beneath it.
  • Use search later when you need the full set of related work.

This keeps the action connected to the thinking that produced it, even when you return to it weeks later.

Good task, good context. “Send the proposal” is more useful when the note also says which proposal, for whom, and why it matters.
