Basic functionality

Tags

Use a small, consistent vocabulary to connect notes without building a rigid filing system.

Use tags as a light index

Tags are a flexible way to group notes without building a rigid filing system. Add a tag anywhere in a note with a #, then use the same language consistently for the themes you revisit.

A few useful tags
#client #launch #research #waiting

Prefer a small vocabulary that you will actually use. A tag should help you find or connect work, not become another system to maintain.

Choose a vocabulary you will keep

  • Use the same tag for the same kind of work.
  • Keep names short enough to add without thinking.
  • Choose one or two useful tags instead of tagging every sentence.

Tags work best when they stay predictable. You should be able to remember the tag later, even when you are searching from a different note.

Use tags with search

When you need the full set of related work, search for the tag. MellowMill searches across your notes, tasks, tags, and files, so a tag can lead you back to the context around each result.

Keep tags light. If a tag needs its own explanation, it may be doing the work of a notebook or a note title instead.
