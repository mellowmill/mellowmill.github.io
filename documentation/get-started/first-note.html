Get Started

Create your first note

A good first note does not need to be a template. Give the work a name, capture what matters, and leave yourself a clear next move.

Start with the work in front of you

Choose something real: a client conversation, a project kickoff, or the decision you keep having to explain. Write the title first, then add the context that will save you time later.

Example Margin note
Project kickoff
#client #launch

Questions
What does a useful first release need to prove?

Decision
Keep the first release focused on the core workflow.

Next actions
- Confirm the brief, due 5th September
- Share the outline with the team

Give the note a little shape

Margin is designed to keep meaning close to the words. You can use familiar headings and bullet points, then add the structures that help you work:

  • Headings separate context, questions, decisions, and notes.
  • Tasks turn a sentence into something you can track.
  • Tags connect notes by theme, client, or project.
  • Links and files keep supporting material close to the thought that needs it.

See the full Margin format guide for every supported block and a complete document example.

Finish with a next action

Before you leave the note, ask what should happen next. If it is actionable, write it as a task. If it is a question, leave it visible until you have an answer. The point is not to fill every section; it is to make the next return to the note easier.

Keep the first pass small. One useful note is a better starting point than a perfect structure with nothing in it.
